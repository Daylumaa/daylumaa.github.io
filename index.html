Daylumaa SEO Tool

Daylumaa SEO Tool is a private research and listing-optimisation tool built and used by the owner of the Daylumaa Etsy shop. It helps plan which products to make and how to describe them so buyers can find them.

What the tool does

  • Keyword research: looks up how often people search for a keyword on Google (using the Google Ads API Keyword Planner data from the owner's own Google Ads account) and how many Etsy listings compete for it (using the Etsy Open API).
  • Niche finder: scores keyword ideas against criteria the owner sets, such as search volume, competition and price.
  • Listing review: compares the owner's own Etsy listings with top-ranking listings and suggests better titles, tags and descriptions.
  • Trends: shows month-by-month search trends for chosen keywords.

How Google data is used

The tool signs in with Google only to read keyword planning data (search volume, trends and competition) from the owner's own Google Ads account. It does not create, change or run ads, and it does not access anyone else's Google account. Data is stored only on the owner's computer.

Who can use it

The tool is used only by the Daylumaa shop owner. It is not offered to the public and has no user sign-ups.
