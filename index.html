Daylumaa SEO Tool

A keyword and listing research tool for the Daylumaa Etsy shop. It helps decide which products to make and how to describe them so buyers can find them.

  • Keyword research: how often people search for a keyword on Google (Google Ads API Keyword Planner data from the owner's own Google Ads account) and how many Etsy listings compete for it (Etsy Open API).
  • Niche finder: scores keyword ideas against criteria the owner sets, such as search volume, competition and price.
  • Listing review: compares the owner's own Etsy listings with top-ranking listings and suggests better titles, tags and descriptions.
  • Trends: month-by-month search trends for chosen keywords.

More SpotOnEasy tools may be added here in future. Each will be described on this page before it uses any Google data.

How Google data is used

SpotOnEasy signs in with Google only to read keyword planning data (search volume, trends, competition and bid ranges) from the owner's own Google Ads account. It does not create, change or run ads, and it does not access anyone else's Google account. Data is stored only on the owner's computer.

Who can use it

SpotOnEasy tools are currently used only by their owner. They are not offered to the public and have no user sign-ups.
