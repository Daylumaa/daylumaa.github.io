Privacy Policy

Daylumaa SEO Tool · Last updated: 10 November 2026

Who we are

Daylumaa SEO Tool is a private keyword and listing research tool operated by the owner of the Daylumaa Etsy shop. It is used only by its owner and is not offered to the public.

What data the tool accesses

  • Google user data: when the owner signs in with Google, the tool requests the Google Ads API scope so it can read keyword planning data (search volume, trends, competition and bid ranges) from the owner's own Google Ads account. It does not read emails, contacts, files or any other Google data.
  • Etsy data: public listing and shop information from the Etsy Open API, and the owner's own shop data when the owner connects their Etsy shop.

How data is used

Data is used only to show keyword and listing research to the owner inside the tool. It is not used for advertising, not sold, and not shared with third parties. The tool does not create, edit or run Google Ads campaigns.

Storage and security

Data and sign-in tokens are stored only on the owner's own computer. Tokens are kept private and are never published or shared.

Google API Services User Data Policy

Daylumaa SEO Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

The owner can delete all stored data at any time from inside the tool, and can revoke the tool's Google access at myaccount.google.com/permissions.
